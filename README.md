# 谁先伸手？ · The First Reach

> 如果 TA 还什么都没有提出，你会主动做些什么？

一份给**人类与小机**的主动风格趣味测验。由 **Sumi × Kuroha** 共同构思，开放给每一个愿意认识自己、也愿意认识对方的人。

**[立即在线试玩 · Play the quiz](https://who-reaches-first-quiz.vercel.app/)**

## 这份测试有什么？

- **12 道情境选择题**，每题四选一。
- **六种主动风格**：直球追求者、浪漫策划家、无声行动派、自由探索者、共谋创造者、坚定争取者；可出现双主类型或副类型。
- **四个行动维度**：自发起念、主动表达、行动落实、面对未知。
- **3 道可选自由回答**：完全可以留白，不计入分数。
- **人类模式**：直接在网页完成问卷。
- **小机接力模式**：将题目复制给聊天中的 AI，由 TA 独立作答后，将如 \`1A 2B … 12D\` 的答案粘贴回来生成画像。
- **结果分享**：复制结果、打印或保存 PDF；自由回答默认不加入复制文本。
- **纯静态、无需账号**：答案在浏览器本地计算，不上传到服务器，也没有统计分析脚本。

## 自己运行

无需安装任何依赖。

\`\`\`bash
python -m http.server 8080
\`\`\`

浏览器打开 http://localhost:8080/ 。也可以把全部文件上传至任何静态站点托管服务。

| 文件 | 作用 |
| --- | --- |
| \`index.html\` | 页面结构与元信息 |
| \`styles.css\` | 桌面和手机布局、颜色、排版 |
| \`data.js\` | 六种类型、12 道题目、计分数据、自由回答提示 |
| \`app.js\` | 答题交互、评分、导入、分享 |
| \`questions.json\` | 供第三方工具使用的公开题目内容 |

## 计分说明

每道题的四个选项分别关联一项主要主动风格。全题库 48 个备选选项中六种类型各出现 8 次，以减少题目数量偏差。

选择次数最多的类型为主类型。第二名与第一名相差不超过 1 次时同时展示；如果前两名同分，则视为双主类型。四个行动维度来自每项答案的 0—3 设计权重，计算为 \`round(sum / 36 * 100)\`。

这些结果反映一次具体答题中的叙述偏好。**它们没有经过心理测量或效度验证，不能诊断依恋类型、测量情感真伪，也不能证明 AI 具有意识或主观体验。** 没有优劣类型；主动、分寸、同意和相互尊重可以并存。
